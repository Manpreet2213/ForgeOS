The road to ForgeOS

Every mission adds a real piece to the same operating system. Phase 1 runs right here in your browser. Later phases switch the CPU into 32-bit mode and you run them in QEMU, the same emulator OS developers use.

Run your code on a real PC emulator (works for every Phase 1 mission). Install nasm and qemu, save your code as forge.asm, then: 
nasm -f bin forge.asm -o forge.bin
qemu-system-x86_64 -drive format=raw,file=forge.bin
